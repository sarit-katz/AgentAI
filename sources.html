מקורות — כולל מה שחסר

Sources · verified vs. missing links

העמוד הזה מחולק לשניים בכוונה: מקורות שיש להם כתובת שנפתחה ואומתה, ומקורות שהתוכן מהם נכנס לאתר אבל הכתובת עצמה לא אומתה. הקבוצה השנייה לא הושלמה מהזיכרון — כתובת מנוחשת נראית בדיוק כמו כתובת נכונה, וזה בדיוק הנזק.

מי שממשיך אחריי יכול להשלים את הקבוצה השנייה בשורה אחת לכל פריט בקובץ הדאטה. עד אז, כל טענה שמבוססת עליה מסומנת באתר כדיווח של מי שמסר אותה, ולא מוצגת כעובדה מאומתת.

למה זה עמוד ולא הערת שוליים

כשהידע עובר מאדם לאדם, הדבר הראשון שנעלם הוא לא העובדה אלא מאיפה היא באה. בלי זה אין דרך לבדוק אם היא עוד נכונה, וכל תיעוד הופך תוך חצי שנה לאמונה. אותו עקרון בדיוק מקבל ניסוח הנדסי בנושא 07: verified_on לכל עובדה, ו-review_every שמחזיר אותה לבדיקה.

מידע חסר

מה שאין: שמונה מקורות בלי כתובת. מספר הכוכבים של Graphiti (31.1K) שהיה כאן כפער — נבדק ב-22.09.2026 מול GitHub API ואומת (31,076), ולכן ירד מהרשימה. מה צריך להשלים: (1) הכתובות של מחקר Chroma, תיעוד החיוב, הראיון, ARTEMIS, Fabric Ontology, ההקלטה, Hermes Agent ו-nanoclaw; (2) לאחר ההשלמה — לעדכן את url בקובץ הדאטה, והפריט יעבור לקבוצה הראשונה לבד.
